# 报告反馈与假设验证

旧版 Plan 审批中断和 checkpointer 已移除。当前流程先自动完成有限计划，再由用户查看报告并反馈。

## 纠偏

Dashboard 的纠偏入口会把用户补充直接加入原问题，并启动一次新任务。新任务保留原报告供用户比较；模型需要将纠偏作为外部观察纳入计划和解释。

## 确认沉淀

用户确认报告后，经验与新假设写入本地 JSON。没有确认的结果不作为经验检索。

## 后续验证

复盘新视频时，用户可选中历史假设。Agent 在报告中对照新证据给出 supported、weakened 或 inconclusive 状态。只有累计两次 supported 或假设本身达到 high 置信度后，才作为优先历史经验检索。每次验证也需要用户确认后才写入。
