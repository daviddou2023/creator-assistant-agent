# LangGraph 工作流

```mermaid
flowchart TD
  A[用户问题与视频标识] --> B[Plan: 选择必要任务]
  B --> C[Execute: 执行已注册工具]
  C --> D{工具失败且重规划少于两轮?}
  D -- 是 --> E[Re-plan: 根据观察调整 Todo]
  E --> C
  D -- 否 --> F[Verify: 证据与限制]
  F --> G[解释与可验证假设]
  G --> H[生成报告]
  H --> I{用户反馈}
  I -- 纠偏 --> J[将反馈注入问题并重跑]
  I -- 确认 --> K[写入经验 JSON]
  K --> L[后续复盘检索与验证]
```

## 工具约束

- `metrics`: 仅允许从平台可用指标清单中选择键。
- `comments`: 仅在问题需要评论信号时抓取，并记录清洗前后样本数。
- `history`: 先检索同一创作者已确认且高置信度或经多次验证支持的经验。
- 模型不输出内部思维过程；界面展示 Todo、执行事件、证据和结论。
- 不可用的后台指标作为限制展示，不允许用猜测填补。
