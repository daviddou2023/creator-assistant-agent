# 项目说明

## 目标

帮助短视频创作者复盘具体问题：采集平台可访问的指标和评论，计算互动指标，识别评论信号；对异常组合给出带证据、置信度和限制的解释，并把用户确认的结论整理成可由后续视频验证的创作假设。

## 当前流程边界

- 用户输入自然语言问题、视频链接/BV 号和创作者 ID。
- Agent 只计划并调用已注册的指标、评论、经验检索工具。
- 工具失败最多触发两轮重规划。
- 不可取得的指标明确标为缺失，不猜测数值。
- 报告中的解释是证据支持的候选解释，不宣称单条视频数据证明因果。
- 只有用户确认满意的报告会写入经验文件。
- 用户可选中历史假设，在后续视频复盘中追加验证记录。

## 当前数据源

支持 B 站公开数据和本地 JSON 样例。B 站公开数据包括当前累计播放、点赞、转发、收藏、投币、弹幕、评论数及可见评论。用户后台指标如 5 秒跳出率、平均播放时长、完播率和真实观看留存曲线当前不可用。
